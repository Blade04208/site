My own brand design has a very complicated and silly history. I consider the "start" of my brand to be in 2023, when I found myself looking through the standard list of Microsft Fluent Icons and found a set of animal icons: Dog, Cat, Turtle and Rabbit. However, only the rabbit has a disabled variant, which quickly became an in-joke among friends. This "in-joke" evolved several times, starting when doromiert asked me to use a profile picture invoving the icon.
